# 📝 Autocomplete and Autocorrect using NLP

## 📌 Overview

This project was developed as part of the **Oasis Infobyte Data Analytics Internship (Level 2 - Task 5)**.

It demonstrates how Natural Language Processing (NLP) techniques can be used to build:

- Bigram-based Autocomplete System
- Autocorrect using PySpellChecker
- Autocorrect using Levenshtein Distance

The project also evaluates model performance using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.

---

## 📂 Dataset

Alice's Adventures in Wonderland (Project Gutenberg)

Public Domain Text Corpus

- Text preprocessing
