# 🧹 Data Cleaning Project

## Oasis Infobyte Internship - Task 3

### Project Overview

This project demonstrates the complete data cleaning process using Python and Pandas.

The objective is to transform a messy dataset into a clean, analysis-ready dataset by identifying and handling common data quality issues.

---

## Objectives

- Load the dataset
- Explore the dataset
- Check missing values
- Handle missing values
- Check duplicate records
- Remove duplicates
- Validate the cleaned dataset
- Export the cleaned dataset
