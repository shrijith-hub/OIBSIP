# Level 2 Projects

## Task 1 — House Price Prediction

Predict house prices using Linear Regression by analyzing features such as area, location, number of rooms, and property age.

### Skills

- Data Cleaning
- Feature Engineering
- Linear Regression
- Model Evaluation
- Regression Metrics

---

## Task 2 — Wine Quality Prediction

Build classification models to predict wine quality using physicochemical properties.

### Skills

- Classification
- Random Forest
- Decision Tree
- Logistic Regression
- Feature Importance

---

## Task 3 — Google Play Store Analysis

Perform Exploratory Data Analysis on Google Play Store applications and user reviews.

### Skills

- EDA
- Data Visualization
- Data Cleaning
- Sentiment Analysis
- Business Insights

---

## Task 4 — Credit Card Fraud Detection

Develop machine learning models to detect fraudulent transactions using highly imbalanced financial data.

### Skills

- Binary Classification
- Class Imbalance Handling
- Precision & Recall
- Confusion Matrix
- Fraud Analytics

---

## Task 5 — NLP Autocomplete & Autocorrect

Build an autocomplete and autocorrect system using Natural Language Processing techniques.

### Skills

- NLP
- Text Processing
- Tokenization
- Language Modeling
- Edit Distance
- Probability-Based Word Prediction
