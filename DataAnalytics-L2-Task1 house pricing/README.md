# House Price Prediction using Linear Regression

## Project Overview
This project predicts California house prices using a Linear Regression model. It demonstrates the complete machine learning workflow from data loading and preprocessing to model evaluation.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load Dataset
2. Data Exploration
3. Data Cleaning
4. Exploratory Data Analysis
5. Feature Selection
6. Train-Test Split
7. Linear Regression
8. Model Evaluation
9. Save Model

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
