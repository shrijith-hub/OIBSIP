# Customer Segmentation Analysis

## Objective

The objective of this project is to analyze customer purchasing behavior and segment customers based on their sales, profit, and purchase frequency using the Sample Superstore dataset.

## Dataset

- Sample Superstore Dataset

## Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Imported required libraries
2. Loaded the dataset
3. Explored the dataset
4. Checked missing values and duplicates
5. Created customer summary using GroupBy
6. Calculated sales, profit, and purchase frequency
7. Identified top customers
8. Segmented customers into High, Medium, and Low Value
9. Visualized customer segments
10. Generated business insights

## Key Insights

- High-value customers contribute significantly to revenue.
- Most customers belong to the Low Value segment.
- Customer segmentation helps businesses improve marketing strategies and customer retention.
