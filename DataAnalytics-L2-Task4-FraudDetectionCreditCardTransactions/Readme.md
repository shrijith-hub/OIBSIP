## Dataset

The dataset is publicly available on Kaggle and is not included in this repository because it exceeds GitHub's file size limit.

**Download the dataset:**

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

After downloading:

1. Create a folder named `dataset` inside the project directory.
2. Place `creditcard.csv` inside the `dataset` folder.
3. Run the Jupyter notebook normally.

Project structure:

```text
DataAnalytics-L2-Task4-FraudDetectionCreditCardTransactions/
│
├── dataset/
│   └── creditcard.csv
│
├── Fraud_Detection.ipynb
├── images/
├── README.md
└── requirements.txt
```
